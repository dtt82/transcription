# Scribe — коннектор расшифровки для Claude

Мост между Claude и ElevenLabs Speech-to-Text. После установки можно в любом
чате и с любого устройства сказать «расшифруй сегодняшние записи» — Mac mini
при этом может быть выключен.

## Зачем он нужен

Облачные сессии Claude не имеют прямого выхода в интернет. Коннекторы под это
ограничение не попадают — они ходят через сервис Anthropic. Этот сервер живёт
на Render, обращается к ElevenLabs сам и отдаёт Claude готовый текст.

Расшифровка асинхронная: сервер ставит задачу и сразу возвращает
идентификатор, а результат забирается отдельным вызовом. Поэтому
полуторачасовая запись не упирается в таймаут, а сервер может спокойно
засыпать между вызовами — на бесплатном тарифе Render это происходит через
15 минут простоя.

## Что внутри

| Файл | Назначение |
|---|---|
| `server.py` | Сам коннектор: три инструмента и приёмник webhook |
| `requirements.txt` | Зависимости |
| `render.yaml` | Описание сервиса для Render |

Инструменты, которые получит Claude:

- `submit_transcription` — поставить аудио в очередь, вернуть `request_id`
- `get_transcription` — забрать готовую расшифровку, порциями, с таймкодами
  и разделением по говорящим
- `check_status` — проверить, что ключ принимается (минуты аудио не тратятся)

## Установка

### Шаг 1. Ключ ElevenLabs

Кабинет ElevenLabs → **Settings → API Keys → Create API Key**.

Ограничьте права ключа только **Speech to Text**. Он будет лежать в настройках
Render, и в случае чего вы отзовёте его, не трогая основной ключ аккаунта.

Скопируйте ключ сразу — второй раз его не показывают.

### Шаг 2. Репозиторий на GitHub

Создайте новый репозиторий (можно приватный) и загрузите в него четыре файла
из этой папки. Через веб-интерфейс: **Add file → Upload files**, перетащить,
**Commit changes**.

### Шаг 3. Деплой на Render

1. Откройте [render.com](https://render.com) и войдите через GitHub.
2. **New → Blueprint**.
3. Выберите созданный репозиторий — Render сам прочитает `render.yaml`.
4. Он спросит значение `ELEVENLABS_API_KEY` — вставьте ключ из шага 1.
5. `CONNECTOR_TOKEN` Render сгенерирует сам. **Apply**.

Первая сборка — пара минут. Когда статус станет **Live**, откройте вкладку
**Environment** и скопируйте значение `CONNECTOR_TOKEN`.

Проверка: откройте `https://<имя-сервиса>.onrender.com/healthz` — должно
ответить `ok`.

### Шаг 4. Подключение к Claude

Адрес коннектора собирается так:

```
https://<имя-сервиса>.onrender.com/t/<CONNECTOR_TOKEN>/mcp
```

В Claude: **Settings → Connectors → Add custom connector**, вставить адрес,
без OAuth.

Токен в адресе — это и есть защита. Без него сервер отвечает 404, так что
посторонний не сможет тратить ваши минуты.

### Шаг 5. Проверка

В новом чате: «проверь статус коннектора Scribe». Должно ответить, что ключ
принят.

## Необязательно: webhook

Основной способ получения результата — опрос ElevenLabs, он работает сам по
себе. Webhook нужен только как подстраховка.

Если хотите его включить: в кабинете ElevenLabs в разделе webhooks укажите
адрес `https://<имя-сервиса>.onrender.com/webhook`.

## Расходы

- **Render**, бесплатный тариф — $0. Сервис засыпает после 15 минут простоя,
  первый вызов после сна идёт на 30–60 секунд дольше. Для расписания это
  несущественно. Тариф Starter ($7/мес) убирает засыпание, если захотите.
- **ElevenLabs Scribe v2** — $0.22 за час аудио. При четырёх часах записей
  в день выходит около $26 в месяц. План Creator ($22/мес) включает 100 часов.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| Render не стартует, в логах ошибка про переменную | Не задан `ELEVENLABS_API_KEY` либо `CONNECTOR_TOKEN` короче 24 символов |
| Коннектор не подключается | Проверьте, что в адресе есть `/t/<токен>/mcp` целиком |
| `401` при расшифровке | Ключ отозван или у него нет прав на Speech to Text |
| `422` при расшифровке | ElevenLabs не смог скачать файл — ссылка из Plaud истекла, нужна свежая |
| `get_transcription` отвечает `processing` | Расшифровка ещё идёт, повторите через минуту |
